# AI assistance and reuse disclosure

OpenAI Codex provided substantive assistance with interpreting the project interface and constraints, implementing feature extraction and training scripts, running and comparing experiments, investigating validation overfitting, preparing reproducibility records, drafting the README and report, and publishing the repository. The numerical results are outputs of the supplied independent scorer, not estimates or manually entered predictions.

The student author must review the implementation and report, verify the experimental claims, and take responsibility for the submitted work. This disclosure does not assert that this review has already been completed.

No LLM is called during evaluation. No external dataset, additional pretrained model weights, per-question answer lookup, or question ID feature is used. Training supervision comes only from the supplied training references. Validation labels were used in the exploratory development phase; the later cross-validation procedure selects its configuration using training groups only.

Six official test evaluations were made during development. Aggregate test scores were used to monitor progress toward the requested 84% public-bank target, and development continued after earlier scores fell short. This is adaptive use of test feedback and does not follow a strictly one-shot, final-only testing protocol. No individual test reference values or error cases were inspected to fit weights, construct features, or create answer lookups; the official checker/scorer necessarily read references for alignment and grading. Final base-model selection used validation scores, while arithmetic-penalty settings used train-group OOF scores. These narrower safeguards do not make the public test untouched. The full trajectory is retained in `experiments/` and must be disclosed to the instructor; a separate audit bank is needed to assess generalization and the instructor determines eligibility.

The original data, interface, numeric parser, scorer and project guide are reused from [the course repository](https://github.com/xudongwu-0/DASE7506-MP2). The fixed parser and scorer remain unchanged. GSM8K attribution and its retained MIT license are in `code/data/NOTICE.txt` and `code/data/LICENSE.txt`. Candidate text and representations were supplied by the course and produced with Qwen3-0.6B; no Qwen weights are included in this project.
